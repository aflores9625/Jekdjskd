# VIL Doctor — диагностика Windows

`vil-doctor.exe` проверяет Windows 10/11 и сохраняет подробный текстовый отчёт на Рабочий стол.
Программа **только читает** данные: ничего не удаляет, не чинит и не отправляет в сеть.
Единственный сетевой запрос — проверка связи с `www.msftconnecttest.com`, тем же адресом, который использует сама Windows.

## Запуск

Дважды щёлкните `vil-doctor.exe` и подтвердите запрос прав администратора. Без этих прав часть проверок будет пропущена.
Программа спросит, запускать ли глубокую проверку образа Windows (DISM ScanHealth, 5–20 минут).
Затем она пройдёт 13 разделов и откроет отчёт в Блокноте.

```
vil-doctor.exe [--deep | --quick] [--out ПАПКА] [--no-elevate] [--no-open] [--no-pause]
```

Код возврата: `0` — всё хорошо, `1` — есть замечания, `2` — есть критичные проблемы, `3` — не удалось сохранить отчёт.

## Что проверяется

| Раздел | Проверки |
| --- | --- |
| Система | версия и срок поддержки Windows, активация, время без перезагрузки, память, индекс стабильности |
| Диски | свободное место, SMART, износ и температура SSD, ошибки чтения/записи, флаг повреждения тома |
| Системные файлы | 73 ключевых файла System32/SysWOW64, Media Foundation (редакции N), DISM CheckHealth / ScanHealth |
| Библиотеки | Visual C++ 2010–2022, DirectX 9–11 для игр, .NET Framework 3.5/4.8, современный .NET, WebView2 |
| Обновления | давность установки, отключённая служба/политика, пауза, ожидающая перезагрузка |
| Безопасность | антивирус и базы, найденные угрозы, брандмауэр, UAC, SMB1, «Гость», RDP, Secure Boot, TPM |
| Службы | важные службы, остановленные автоматические службы, службы и драйверы без исполняемых файлов |
| Устройства | ошибки Диспетчера устройств с расшифровкой кода, драйвер видеокарты, износ аккумулятора |
| Журнал событий | синие экраны и дампы, внезапные выключения, WHEA, ошибки диска, падения и зависания программ |
| Автозагрузка | записи на удалённые файлы, их количество, подмена Winlogon, перехват IFEO |
| Битые ссылки | ярлыки на удалённые файлы, программы без деинсталлятора, задания планировщика, мусор в PATH |
| Сеть | адаптеры, DNS, доступ в интернет, перехват трафика, точность часов, прокси, файл `hosts` |
| Производительность | временные файлы и кэш обновлений, файл подкачки, самые «тяжёлые» процессы |

Отчёт открывается итогом и списком «Что сделать в первую очередь». Дальше идут разделы с фактами, найденными проблемами и конкретными шагами исправления.
В конце — приложения: все записи автозагрузки, установленные программы и частые ошибки журнала.

## Сборка

```
cargo build --release                                   # на Windows
cargo build --release --target x86_64-pc-windows-gnu    # кросс-сборка (нужен mingw-w64)
cargo test                                              # логика тестируется на любой ОС
```

Данные собираются через встроенный Windows PowerShell 5.1: каждая проверка — короткий скрипт, который возвращает JSON.
Оценка, пороги и текст отчёта — на Rust. Проверки идут параллельно в три потока, результат выводится по порядку.
