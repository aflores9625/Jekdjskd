# VIL Doctor — диагностика Windows

`vil-doctor.exe` проверяет Windows 10/11 и сохраняет подробный текстовый отчёт на Рабочий стол.
Программа **только читает** данные: ничего не удаляет, не чинит и не отправляет в сеть.
Единственный сетевой запрос — проверка связи с `www.msftconnecttest.com`, тем же адресом, который использует сама Windows.

## Запуск

Распакуйте архив и запустите `vil-doctor.exe`: откроется окно программы. `WebView2Loader.dll` должен лежать в той же папке.
На первом экране видно, есть ли права администратора: без них часть проверок пропускается, а кнопка «Запросить права» перезапускает программу через UAC. Там же включается глубокая проверка образа (DISM ScanHealth, 5–20 минут).
Во время проверки слева видно состояние каждого раздела, готовые разделы можно открывать сразу.
В итоге — индекс здоровья, список «Что сделать в первую очередь», подробности по разделам и кнопки «Открыть отчёт» / «Показать в папке».
Текстовый отчёт сохраняется на Рабочий стол автоматически.

Окну нужен Microsoft Edge WebView2 Runtime: он входит в Windows 11 и обычно уже установлен в Windows 10.

Консольная версия `vil-doctor-cli.exe` делает то же самое без окна:

```
vil-doctor-cli.exe [--deep | --quick] [--out ПАПКА] [--no-elevate] [--no-open] [--no-pause]
```

Код возврата консольной версии: `0` — всё хорошо, `1` — есть замечания, `2` — есть критичные проблемы, `3` — не удалось сохранить отчёт.

## Что проверяется

| Раздел | Проверки |
| --- | --- |
| Система | версия и срок поддержки Windows, активация, время без перезагрузки, память, индекс стабильности |
| Диски | свободное место, SMART, износ и температура SSD, ошибки чтения/записи, флаг повреждения тома |
| Системные файлы | 73 ключевых файла System32/SysWOW64, Media Foundation (редакции N), DISM CheckHealth / ScanHealth |
| Библиотеки | Visual C++ 2010–2022, DirectX 9–11 для игр, .NET Framework 3.5/4.8, современный .NET, WebView2 |
| Обновления | давность установки, отключённая служба/политика, пауза, ожидающая перезагрузка |
| Безопасность | антивирус и базы, найденные угрозы, брандмауэр, UAC, SMB1, «Гость», RDP, Secure Boot, TPM |
| Службы | важные службы, остановленные автоматические службы, службы и драйверы без исполняемых файлов |
| Устройства | ошибки Диспетчера устройств с расшифровкой кода, драйвер видеокарты, износ аккумулятора |
| Журнал событий | синие экраны и дампы, внезапные выключения, WHEA, ошибки диска, падения и зависания программ |
| Автозагрузка | записи на удалённые файлы, их количество, подмена Winlogon, перехват IFEO |
| Битые ссылки | ярлыки на удалённые файлы, программы без деинсталлятора, задания планировщика, мусор в PATH |
| Сеть | адаптеры, DNS, доступ в интернет, перехват трафика, точность часов, прокси, файл `hosts` |
| Производительность | временные файлы и кэш обновлений, файл подкачки, самые «тяжёлые» процессы |

Отчёт открывается итогом и списком «Что сделать в первую очередь». Дальше идут разделы с фактами, найденными проблемами и конкретными шагами исправления.
В конце — приложения: все записи автозагрузки, установленные программы и частые ошибки журнала.

## Интерфейс

Белый, без градиентов и декоративных эффектов, в духе системных настроек macOS/iOS: светло-серая боковая панель, белая область контента.
Акцентный цвет — синий `#0071e3`: кнопки, переключатель, прогресс, выбранный раздел. Статусы передаются небольшими цветными точками, итог — кольцом с баллом.
Шрифт — Segoe UI Variable, в заголовках отрицательный трекинг.

**Логотип** — стоковая иконка [Lucide](https://lucide.dev) «heart-pulse» (лицензия ISC, см. `assets/LICENSE-lucide.txt`) на синей плашке.
Одна и та же иконка стоит везде: в exe (`assets/icon.ico`, встраивается `build.rs`), в заголовке окна и на панели задач, на стартовом экране и в боковой панели.
На размерах 16–24 px остаётся только сердце, иначе кардиограмма сливается.

**Анимации** подобраны по частоте:
- Один раз за запуск: сердце и кардиограмма рисуются линией, текст появляется каскадом с шагом 60 мс.
- Один раз за проверку:
  - уход со стартового экрана за 180 мс;
  - каскад разделов в боковой панели (25 мс);
  - кардиограмма, бегущая по логотипу, пока идёт проверка (1,4 с, линейно);
  - статус раздела появляется из `scale(0.9)`;
  - в итоге кольцо дорисовывается до балла за 900 мс, а цифры отсчитываются.
- Часто: переход между разделами — 150 мс, едва заметно; карточки раздела появляются каскадом только при первом открытии.
- Нажатие: `scale(0.97)` за 100 мс, наведение только на устройствах с мышью.
- При включённом «уменьшении движения» остаются только короткие проявления, без рисования, петель и сдвигов.

Интерфейс — один файл `src/gui/index.html`, встроенный в exe; с Rust он общается через IPC WebView2.

## Сборка

```
cargo build --release                                   # на Windows
cargo build --release --target x86_64-pc-windows-gnu    # кросс-сборка (нужен mingw-w64); рядом с exe положите WebView2Loader.dll из webview2-com-sys/x64
cargo test                                              # логика тестируется на любой ОС
```

Данные собираются через встроенный Windows PowerShell 5.1: каждая проверка — короткий скрипт, который возвращает JSON.
Оценка, пороги и текст отчёта — на Rust, в общей библиотеке `vil_doctor`, которую используют обе версии. Проверки идут параллельно в три потока, результат выводится по порядку.
